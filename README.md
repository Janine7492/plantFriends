# Plant Friends


Plant Friends entstand als Case Study im Rahmen einer Weiterbildung an der Digitale Leute School im Bereich “Product Design”. 
Die Aufgabe bestand darin, ein echtes Problem zu finden und über die Dauer der Weiterbildung, das Gelernte direkt in der Case Study umzusetzen.

Dieses Repo ist die Umsetzung des erarbeiteten Designs in React mit Typescript und SCSS.
